# M7 设计规范：AI 创作工坊与全流程选题大纲生成（In-Studio AI Creator & Research Engine）

- 日期：2026-11-17
- 状态：已批准（Approved）
- 模块：`mg-studio/lib/research.js` + `mg-studio/lib/ai-generator.js` + `mg-studio/scripts/studio.js` + `mg-studio/lib/studio.html`
- 目标：终结“只有演播监看界面、缺少内容创作入口”的断层痛点，在 Studio UI 中直接打通“资料检索 → 事实库提取 → 故事大纲规划 → 自动分镜生成 → 载入演播室”的全流程闭环。

---

## 1. 核心问题与设计原则

### 1.1 核心问题
目前 `mg-studio` 的 Studio UI 定位于中后期的“排版微调与监看演播室”，而前期的“选题、文献资料检索、叙事大纲规划、分镜生成”需要用户手动编写 JSON 或在终端通过 Agent 手工创建，导致普通创作者找不到“内容从何而来”的入口。

### 1.2 设计原则
1. **全链路向导（Creator Wizard）**：在 Web 工作台顶栏提供一键发起的“AI 视频策划工坊”，通过 4 步向导引导用户完成从主题到成片的策划。
2. **真实权威文献检索**：接入 Europe PMC 与 OpenAlex 等权威医学与科学数据库开放接口，自动检索权威文献、临床指南与核心数据。
3. **确定性规范保障**：生成的 `story.json` 与 `scenes/*.json` 必须 100% 符合 IR v2 schema、叙事模板角色约束及医学安全门（`medical-lint`），零脚本语法与排版错误。
4. **全动态交互闭环**：左侧大纲树支持交互式动态增删分镜卡片（`add`、`delete`、`reorder`），支持创作者随心所欲调整剧本结构。
5. **按需采用稳定方案**：不局限于零外部依赖，网络请求与数据处理采用健壮、带自动重试与超时回退的高可用方案。

## 3. 后端 API 规范与协议定义

### 3.1 `POST /api/research`
- **请求体**：
  ```json
  {
    "query": "房颤冷冻消融与脉冲消融",
    "maxResults": 6
  }
  ```
- **响应体**：
  ```json
  {
    "ok": true,
    "query": "房颤冷冻消融与脉冲消融",
    "articles": [
      {
        "title": "Pulsed Field Ablation versus Cryoballoon Ablation for Atrial Fibrillation",
        "journal": "New England Journal of Medicine",
        "year": "2024",
        "doi": "10.1056/NEJMoa...",
        "abstract": "..."
      }
    ],
    "extractedFacts": [
      {
        "claim": "脉冲电场消融具备组织选择性，降低周围食管和膈神经损伤风险",
        "source": "New England Journal of Medicine 2024",
        "verified": false
      }
    ]
  }
  ```

### 3.2 `POST /api/create-project`
- **请求体**：
  ```json
  {
    "topic": "急性心肌梗死黄金救治",
    "audience": "patient",
    "template": "science",
    "durationTarget": 45,
    "style": "clean-medical",
    "facts": [
      { "claim": "胸痛超过15分钟高度警惕心梗", "source": "中国心血管健康与疾病报告2023", "verified": true }
    ]
  }
  ```
- **响应体**：
  ```json
  {
    "ok": true,
    "projectDir": "...",
    "story": { ... },
    "scenes": [ ... ],
    "compile": { "ok": true, "mode": "v2" }
  }
  ```

### 3.3 分镜动态增删改 API
- `POST /api/beat/add`：插入新 Beat，自动生成匹配布局的场景 JSON。
- `POST /api/beat/delete`：删除指定 ID 的 Beat 及 `scenes/<id>.json`。
- `POST /api/beat/reorder`：传入新的 Beat ID 数组，同步调整 `story.beats` 顺序。

## 4. 前端交互设计与用户体验

1. **顶栏醒目入口**：设计渐变色胶囊按钮 `[ ＋ 新建视频 (AI 创作工坊) ]`。
2. **4 步向导卡片式步进器**：
   - 步骤 1：主题、受众、结构、时长、初始风格选择。
   - 步骤 2：一键检索学术证据，卡片化展示论点，支持自由勾选与追加。
   - 步骤 3：一键生成分镜大纲预览，直观展示 Beat 角色、情绪星级、预分配 MG 组件与旁白文案。
   - 步骤 4：点击一键载入，工作台无缝重载，画布立即播放。
3. **左侧大纲树交互升级**：
   - 顶部增加 `[ ＋ 添加分镜 ]` 按钮。
   - 分镜卡片悬浮显示 `[ ↑ ]`、`[ ↓ ]` 与 `[ 🗑️ ]` 操作按钮，点击即时生效。
